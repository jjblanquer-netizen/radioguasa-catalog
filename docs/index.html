RadioGuasa – copia de respaldo del catálogo

Esta página aloja ficheros JSON con las emisoras más escuchadas de cada país. La app RadioGuasa los usa únicamente cuando el directorio principal no está disponible.

Los datos proceden de Radio Browser y se actualizan una vez al día. Los nombres y logotipos de las emisoras pertenecen a sus titulares.

Si eres titular de una emisora y quieres que se retire, escribe a [CORREO].
